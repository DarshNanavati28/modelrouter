THE ROUTING CONTRACT

Safety first. Preference second.

ModelRouter estimates input size and task difficulty, removes every endpoint that breaks a hard limit, then ranks the eligible set. If an attempt fails, the next model must pass the same checks and fit the remaining end-to-end budget.
